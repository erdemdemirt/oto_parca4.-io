# EŞPARÇA — Muadil Oto Yedek Parça

TanStack Start, TypeScript, React ve Tailwind CSS ile geliştirilmiş oto yedek parça katalog ve sipariş yönetim uygulaması.

## Kurulum ve Çalıştırma

```sh
npm install
npm run dev
```

## Teknolojiler

- TanStack Start & TanStack Router
- TypeScript
- React
- Tailwind CSS
